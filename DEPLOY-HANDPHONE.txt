PANDUAN DEPLOY DARI HP

1. Ekstrak ZIP ini.
2. Buka GitHub dan buat repository baru: autoclip-ai.
3. Upload semua isi folder hasil ekstrak ke repository.
4. JANGAN upload API key ke GitHub.
5. Buka Railway dan login.
6. New Project -> GitHub Repo -> pilih autoclip-ai.
7. Buka service -> Variables.
8. Tambahkan:
   OPENAI_API_KEY = API key OpenAI kamu
   OPENAI_TEXT_MODEL = gpt-5.6-luna
   OPENAI_TRANSCRIBE_MODEL = gpt-4o-mini-transcribe
   MAX_FILE_SIZE_MB = 800
   CLIP_COUNT = 5
9. Deploy / Redeploy.
10. Settings -> Networking -> Generate Domain.
11. Buka URL tersebut dari HP.
12. Upload video -> Buat Clip Otomatis -> download hasil.
